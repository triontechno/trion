# Binary/ternary translator

This directory is reserved for TRION's binary ↔ balanced-ternary interoperability tools.

Planned responsibilities:
- Convert integer and byte-oriented binary representations to and from balanced-ternary values.
- Define explicit signedness, width, overflow, and serialization rules.
- Provide deterministic test vectors shared with `../core/`.

Status: scaffold only; no production implementation has been added yet.
